Privacy policy

Last updated: 21 November 2026

Content Studio is a personal desktop app used only by its developer to manage his own YouTube channel. It is not offered to the public.

What data the app uses

With permission given through Google's sign-in screen, the app uses Google's official YouTube Data API and YouTube Analytics API to upload and schedule videos, read view statistics, and post comments on the developer's own channel.

Where data is stored

The sign-in token and statistics are stored only on the developer's own computer. Nothing is sent to any other server, sold, or shared with third parties.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Google API Services

Content Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API Services are used under the YouTube Terms of Service and the Google Privacy Policy.
